Ovaj repozitorijum služi kao sandbox okruženje za istraživanje naprednih Java koncepata, sa posebnim fokusom na automatizovano testiranje, refaktorisanje koda i primenu čistih inženjerskih principa.
Tehnologije i Alati
• JUnit 5: Framework za pisanje i izvršavanje unit testova.
• Mockito: Alat za kreiranje "mock" objekata i izolaciju poslovne logike tokom testiranja.
• Maven: Upravljanje zavisnostima i automatizacija build procesa.

Implementirani koncepti
• Unit Testing: Pokrivanje ključnih metoda testovima kako bi se osigurala ispravnost algoritama.
• Mocking Dependencies: Simulacija eksternih zavisnosti (poput baza podataka ili API servisa) pomoću Mockito-a, čime se omogućava testiranje komponenti u izolaciji.
• Exception Testing: Verifikacija da sistem pravilno reaguje na nevalidne ulaze i neočekivane situacije.
• Clean Code: Kontinuirano refaktorisanje koda u cilju postizanja niske spregnutosti (low coupling) i visoke kohezije (high cohesion).
